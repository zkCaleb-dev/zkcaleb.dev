# zkcaleb.dev

## Design Context

### Users
Recruiters and technically curious visitors. They come to see what Caleb builds
and how he thinks — active projects and a running devlog — not a static CV.
Reading context: desktop or phone, evening browsing, no urgency.

### Brand Personality
Builder, curious, grounded. An engineer's logbook, not a showcase. Confident
without shouting; the work speaks.

### Aesthetic Direction
Dark theme with WARM neutrals (hot ink, not blue-gray) and an amber/terracotta
accent — deliberately far from the neon-on-dark dev-portfolio cliché.
Concept: engineering notebook / build log. Log-entry numbering (#001),
timestamps, project status labels. Typography: Bricolage Grotesque (display),
Source Serif 4 (prose), Fragment Mono (metadata only).

### Design Principles
1. The log is alive — the site reads as a record of ongoing work, never a frozen brochure.
2. Warm dark: no pure black, no neon, no glassmorphism, no gradient text.
3. Hierarchy by space and type contrast, not boxes — no card grids.
4. Mono is for metadata (dates, tags, status), never for body text.
5. Every word earns its place; short headline, no filler bio prose.
